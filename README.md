# LLMPolicyMesh Demo

Runnable examples and tests demonstrating the LLMPolicyMesh .NET package.

**LLMPolicyMesh** brings programmable AI policy and gateway-style controls directly into .NET applications—in a single in-process layer.

## Capabilities

* Privacy redaction
* Prompt-injection defense
* Tool-call controls
* Retrieval-chunk controls
* Budget enforcement
* Retries
* Circuit breaking
* Fallback routing
* Safe streaming
* Auditability
* Tracing
* Metrics

Addressing concerns also handled by stacks such as [LiteLLM](https://github.com/BerriAI/litellm), [Portkey](https://github.com/Portkey-AI/gateway), [NeMo Guardrails](https://github.com/NVIDIA/NeMo-Guardrails), and [Guardrails AI](https://github.com/guardrails-ai/guardrails)—without requiring separate gateway infrastructure.
